# public/

This folder holds static assets copied verbatim into `dist/` during build.

- `manifest.json` — a build-independent reference copy of the extension manifest. The **actual** manifest used by the build is generated by CRXJS from `manifest.config.ts` at the project root; that is the source of truth. This file exists so the manifest shape is inspectable without running the build, and mirrors `manifest.config.ts` field-for-field.
- `icon-48.png` / `icon-128.png` — placeholder extension icons (1x1 transparent PNGs). Replace these with real artwork before publishing to the Chrome Web Store.
- `monaco/` — NOT committed. Copy `node_modules/monaco-editor/min/vs` here before building (see root README Quick Start). This is required for the options page's Monaco editor to load.
